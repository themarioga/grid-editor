Responsive utilities

Bootstrap's responsive utility classes, edited per breakpoint. Pick a breakpoint in the dropdown and every change is written for that breakpoint alone; in All sizes it is written once, for every size. Each drawer's gear has a Responsive section with a field per utility, which says what the breakpoint inherits and from where.

Visibility: the eye in a drawer hides the node in the view being edited. It stays on the canvas, faded, so you can show it again; in All sizes a badge says at which breakpoints it is hidden. The sidebar below is hidden on phones and tablets.

Order: the arrows in a column's drawer move it earlier or later in the view being edited, without moving the markup. In the second row, "Second" comes first on phones only.

Alignment: fields in the panel of a row (justify and align its columns) and of a column (align itself). The third row centres its narrow column from small desktop up.

Gutters: fields in a row's panel. A row with gutter classes is drawn with its real gutters; the second row has none on phones and wide ones from small desktop up.

Spacing: a padding and a margin group in every panel, each a side and a value. The centred column below gets more padding from small desktop up.

Text alignment: a field in every panel. The centred column's text is centred from small desktop up. Float: a field in an element's panel; the quote in the last row floats to the end from tablet up, with the text flowing round it.
