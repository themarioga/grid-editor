Wrapped content

The editor below was started on plain markup — a heading, a paragraph and a list, with no .row or .col-* anywhere. Grid editor does not refuse it: it wraps all of it into one row with a single col-lg-12 column, and from there it is an ordinary grid. Add rows, split the column, edit the text, then press Refresh to see the html that comes out: as getHtml returns it, to save and edit again, and as getPlainHtml returns it, to publish.
