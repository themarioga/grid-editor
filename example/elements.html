Element level controls

An element is a node inside a content area that the editor treats as one movable, deletable thing instead of as rich text. The host marks them with data-ge-element, optionally naming them with data-ge-label. Each one gets a drawer of its own: move, an info tool, the host's own tools, and delete. They drag between content areas as well as within one.

Click the text around an element to edit it as text; the element itself stays atomic while the editor is open.
