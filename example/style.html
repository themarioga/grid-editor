Style

The gear of a row, a column, a container, a tab, an element or a section has a Style accordion: size, spacing, border, background, text, typography, display, flex, position and free css. What you type is written to the node's own style; a value the browser does not take is marked and not written.

Each section also offers Bootstrap's classes for what it styles, as chips: one puts its class in the classes field, and pressing it again takes it off. Bootstrap's utilities are !important, so a field whose property a class on the node also sets says the class wins.

The inline style is the same at every size. Padding and margin, text alignment, display, flex, sticky and float are Bootstrap's responsive classes, edited per breakpoint in their sections: pick a breakpoint in the dropdown. A node that is flex or grid has its drawer on top, out of the flow, so its content is laid out as on the page.
