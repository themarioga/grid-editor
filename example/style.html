Style and responsive utilities

Inline style. The gear of a row, a column, a container, a tab, an element or a section has a Style accordion: size, spacing, border, background, text, typography, display, flex, position and free css. What you type is written to the node's own style; a value the browser does not take is marked and not written. The inline style is the same at every size.

Bootstrap's classes. Each section also offers Bootstrap's classes for what it styles, as chips: one puts its class in the classes field, and pressing it again takes it off. Bootstrap's utilities are !important, so a field whose property a class on the node also sets says the class wins.

Per breakpoint. Padding and margin, text alignment, display, flex, sticky and float, in the Style accordion, and order, a column's alignment and gutters, in the Responsive section, are Bootstrap's responsive classes. Pick a breakpoint in the toolbar's dropdown and a change is written for that breakpoint alone; in All sizes it is written once, for every size. Every field says what the breakpoint inherits and from where.

  • Display: the eye in a drawer hides the node in the view being edited, faded so you can show it again. The sidebar of the third row is hidden on phones and tablets.
  • Order: the arrows in a column's drawer move it without moving the markup. In the fourth row, "Second" comes first on phones only.
  • Gutters: the fourth row has none on phones and wide ones from small desktop up.
  • Alignment and spacing: the fifth row centres its column from small desktop up, which gets more padding and centred text there too.
  • Float: the quote in the last row floats to the end from tablet up, with the text flowing round it.
  • Flex: a node that is flex has its drawer on top, out of the flow, so its content is laid out as on the page.
