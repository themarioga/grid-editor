The jQuery API

grid-editor needs no jQuery since 7.0. A page written for 6.x loads jQuery 4 and grideditor.jquery.js after the editor, and its code runs as it did: $('#myGrid').gridEditor(...), the methods by name, jQuery event listeners and callbacks with jQuery objects in their payloads. The plugins are 7.0's; a plugin written for 6.x is the one thing to port, as UPGRADING.md explains.

Add a row and the callback counts its columns. The first row carries a locked class, which the event listener reads to turn its delete away.
