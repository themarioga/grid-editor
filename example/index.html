Grid Editor demos

Every page here is a working editor. They are static: served from any web server, or from GitHub Pages, with no build step. Each one runs the built files in dist/, so run npm run build after changing anything under src/.

Since 4.0 every gesture works with a finger as well as with a mouse — sorting, resizing a column, dragging a button off the toolbar — so these are worth opening on a phone. The editor needs jQuery, SortableJS and Bootstrap 5; the first demo loads jquery.grideditor.bundle.min.js instead, which is the editor and SortableJS in one file.
