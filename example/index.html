Grid Editor demos

Every page here is a working editor. They are static: served from any web server, or from GitHub Pages, with no build step. Each one runs the built files in dist/, so run npm run build after changing anything under src/.

Every gesture works with a finger as well as with a mouse — sorting, resizing a column, dragging a button off the toolbar — so these are worth opening on a phone. The editor needs SortableJS and Bootstrap 5; The editor loads grideditor.bundle.min.js instead, which is the editor and SortableJS in one file.

Playground playground.html
Every plugin on one canvas, with the settings above it to turn things on and off, the options as code, and the events as they fire

The source button's html in a code editor, and edit_source to leave the button out
Text editors text-editors.html
TinyMCE, CKEditor 5, summernote and one written in the page as a plugin, on the textTypes hook: one at a time or all together
Containers containers.html
Tabs, accordions, popups, offcanvases and cards, two levels deep, and the export opened as a real page
Elements elements.html
