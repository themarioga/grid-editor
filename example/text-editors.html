Text editors

What edits the text in a column is a plugin: TinyMCE, CKEditor and summernote ship with grid-editor, and any other is a plugin of your own. This page loads all four; content_types chooses the shipped ones an editor offers, and the plugins setting the page's own.

  • TinyMCE
  • CKEditor 5
  • Summernote
  • Simple text
  • All together

TinyMCE 7, inline: content_types: ['tinymce'], and its config in tinymce.config.

CKEditor 5, its browser build: content_types: ['ckeditor'], and anything InlineEditor.create takes in ckeditor.config. It does not start without a licenseKey, and the console says why.

Summernote 0.9, the Bootstrap 5 build: content_types: ['summernote'], and its options in summernote.config. Summernote needs jQuery; grid-editor does not, and drives it without the jQuery adapter.

No shipped editor offered: content_types: []. The text editor is the plugin in this page's source, a few dozen lines on the browser's contenteditable, declaring its type with the textTypes hook. See docs/plugins.md.

Every editor at once. The toolbar has a Text button per editor, a click on the plain content asks which one to make it, and each text opens with the editor it was saved with.
