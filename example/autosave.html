Grid Editor example - autosave and import/export

The autosave plugin keeps what you edit in localStorage, a second after each change and when you leave the page - with a text still open, which it does not close. Reload the page after a change and it offers the draft back. An imported file is a document of its own, with its own autosave.key, so its draft and the page's never step on each other.
