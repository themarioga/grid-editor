Six breakpoints, and "all sizes"

The dropdown on the right of the toolbar picks the layout mode. In All sizes the canvas renders as the browser would, and the width and indent tools write every breakpoint at once. Pick a single breakpoint and the canvas narrows to that tier's width, that tier's classes become the effective ones whatever your window is doing, and the tools write only that tier.

The row below starts with a different size per tier, so switching modes visibly changes it: 3 units on phone, 4 on tablet, 6 on desktop, 8 on widescreen. The second row shows offsets, which are indented per tier in the same way.
