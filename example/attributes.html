A plugin with a modal

The tool in the drawer of a row, a column, a card or an element is a plugin written on this page. It opens a modal, and what you choose there is saved on the node as a data-animation attribute, which getPlainHtml keeps: only data-ge-* attributes are the editor’s to take off. A node with an animation has its tool highlighted.

The quote is an element, inside text tinyMCE edits. Open the editor there, set an animation on the quote, keep typing and press Ctrl+Z: the text goes, the animation stays, because the plugin wrote it through tinyMCE’s undo manager. Written behind its back, undoing the typing would undo the attribute with it.

Open as a published page puts the plain html in a page of its own, with a few lines that read the attribute and animate each node as it scrolls into view.
