A plugin with a modal

The tool in the drawer of a row, a column, a text, a card or an element is a plugin written on this page. It opens a modal, and what you choose there is saved on the node as a data-animation attribute, which getPlainHtml keeps: only data-ge-* attributes are the editor’s to take off. A node with an animation has its tool highlighted.

Open tinyMCE on a text and set an animation on that same text, from its drawer, while you are typing: the attribute is kept when the editor closes, although tinyMCE puts back the attributes it found when it opened. The plugin does nothing special for that - a plain setAttribute() - and nothing special for the quote either, which is an element: a block beside the texts, never inside one.

Open as a published page puts the plain html in a page of its own, with a few lines that read the attribute and animate each node as it scrolls into view.
