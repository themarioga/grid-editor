Plugins

Tabs, accordions, popups, cards and the element level controls are not in the main bundle: each is a file loaded beside the editor, and loading it is what turns the feature on. This page loads all five, plus a sixth written in its own <script> below.

Tick and untick to change the plugins setting and re-initialize the editor. A container plugin puts a button in the toolbar; elements has no button — its effect is that the marked markup in the first row becomes a movable element.
